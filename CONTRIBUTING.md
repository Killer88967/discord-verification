# Contributing to Discord Verification Bot

Thanks for your interest in contributing to Discord Verification Bot.

Contributions including bug fixes, documentation improvements, new
features, tests, and security improvements are welcome.

## Development

This project is a pnpm monorepo.

Clone the repository and install dependencies:

```bash
pnpm install
```

Start the development environment:

```bash
pnpm dev
```

Individual applications and packages can also be run through their
respective workspace commands.

## Before submitting a pull request

Please make sure that:

- Your changes build successfully.
- Existing behavior is not unintentionally broken.
- New functionality is reasonably documented.
- Sensitive information, tokens, credentials, and `.env` files are not committed.
- Changes follow the existing TypeScript and project conventions.
- Unrelated changes are not bundled into the same pull request.

## Pull requests

Please describe:

- What changed.
- Why the change is needed.
- Any security implications.
- How the change was tested.

Small and focused pull requests are preferred.

## Security-related changes

Do not publicly disclose exploitable security vulnerabilities through
GitHub Issues.

Please follow the instructions in [SECURITY.md](SECURITY.md).
