# Support

Discord Verification Bot is currently under active development.

## Bugs

If you believe you have found a bug, please use the GitHub bug report
template.

## Feature requests

Feature suggestions are welcome through the GitHub feature request
template.

## Security vulnerabilities

Do not report exploitable security vulnerabilities through public issues.

See [SECURITY.md](SECURITY.md) instead.

## Self-hosting

Community support for self-hosted installations is provided on a
best-effort basis.

Please include relevant logs, environment information, package versions,
and reproduction steps when asking for help.

Never publish Discord bot tokens, API keys, database credentials,
internal API secrets, or other sensitive configuration values.
